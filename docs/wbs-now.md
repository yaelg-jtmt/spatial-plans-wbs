# מסך ה-WBS: מה קורה עכשיו בתכנית

## מה רואים
1. **סיכום עליון:** שם התכנית, אחוז, יעד, אחראי, חסם והפעולה הבאה של התכנית, ושבעת השלבים עם ספירה לכל שלב. השלב הנוכחי מסומן "כעת", ולחיצה על שלב מסננת אליו.
2. **אריחי ספירה:** בעבודה, מוכנות להתחלה, ממתינות לקודמת, ממתינות להחלטה, מעוכבות, הושלמו. אריח הוא גם מסנן.
3. **ארבעה פאנלים:** בעבודה עכשיו, מוכנות להתחלה, ממתינות להחלטה, מעוכבות או ממתינות. פריט פותח את השורה בטבלה, ויש כפתורי עדכון מהיר (הושלמה, התחלתי, נדרש / לא נדרש, חזרה לעבודה).
4. **טבלה:** השלבים הנוכחיים פתוחים, האחרים סגורים עם סיכום בכותרת. כפתור "פרטים" בכל שורה פותח תלויות, תוצר, "משויך לתוצר", הערה ולוח זמנים.

## איך נקבע מצב משימה
| מצב | מתי |
|---|---|
| הושלם | הסטטוס "הושלם" |
| בעבודה | הסטטוס "בתהליך" |
| מוכנה להתחלה | "טרם התחיל", וכל הקודמות הושלמו או אינן נספרות |
| ממתינה לקודמת | "טרם התחיל", ויש קודמת שלא הושלמה |
| מעוכבת / ממתינה | הסטטוס "מעוכב" / "ממתין" |
| לא נספרת | ההחלטה "לא נדרש" או "הוחרג בתכולה המקורית" |

הקודמות נלקחות מעמודת Predecessor. טווח כמו `2.5–2.10` הוא כל השורות מ-2.5 עד 2.10 לפי סדר הטבלה.

## השלב הנוכחי
לפי נתוני התכנית (`active` ו-`lead`). בתכנית שהושלמה: תחזוקה, עם המחזור הבא מהגאנט. בגרסה ב': שלבים 0–4.

## מה אמין בנתונים
- **סטטוס שלא עודכן ידנית** מחושב משלב התכנית בלבד: כל משימות השלב הנוכחי נחשבות "בעבודה". לכן מופיע באריחים משפט שאומר כמה משימות בשלבים הנוכחיים עודכנו ידנית, ומתי עודכן לאחרונה, ובכל שורה "מחושב משלב התכנית" או תאריך העדכון.
- **הבחירות נשמרות בדפדפן** של מי שעדכן, לכל תכנית בנפרד, ואינן משותפות בין משתמשים.
- **"עבר חלון הזמן בגאנט"** מבוסס על תאריכי הגאנט, שהם תכנון ראשוני ולא מאומתים.
- **חסם והפעולה הבאה של התכנית** מוצגים רק לתכנית שלא הושלמה ולא בגרסה ב', כי בתכניות שהושלמו הטקסט המקורי הוא ישן.
