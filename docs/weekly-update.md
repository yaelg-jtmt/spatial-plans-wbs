# עדכון שבועי

האתר מציג שני מקורות: **העדכון השבועי** שמתפרסם בריפו (משותף לכולם), ו**שינויים מקומיים** שנשמרים בדפדפן של מי שעדכן. בכל שורה העדכון המאוחר יותר קובע.

## הנוהל
1. במהלך השבוע אפשר לעדכן סטטוסים באתר כרגיל (הם נשמרים בדפדפן).
2. פעם בשבוע: "ייצוא העדכונים שלי" (בראש מסך ה-WBS) מוריד קובץ `wbs-update-<תאריך>.json`.
3. שולחים לי את הקובץ, ובנוסף כותבים בחופשיות מה השתנה ברמת התכנית (אחוז, חסם, פעולה הבאה, שלב נוכחי, תכנית שהושלמה).
4. אני מכינה חבילה מעודכנת. ב-Codespaces: `unzip -o <קובץ>`, `npm run test:sync`, commit ו-push.

## מה נכנס לאן
| מה | קובץ |
|---|---|
| אחוז, סטטוס, חסם, פעולה הבאה, יעד, אחראי, QA, שלבים פעילים, completed | `public/data/plans.json` |
| סטטוס, החלטה, אחראי, הערה ותוצרים של משימות WBS | `public/data/wbs-status.json` |

## הרצה ידנית
```
node scripts/apply-weekly-update.mjs update.json --dry     # הצגת השינויים בלי לכתוב
node scripts/apply-weekly-update.mjs update.json --date 2026-12-01
```
הסקריפט בודק תכניות, שורות וערכים, ואם יש שגיאה אינו כותב כלום. הרצה חוזרת של אותו קובץ אינה משנה דבר. `null` בשורה מוחק את העדכון שלה.

## מה לא נכנס
- **גרסה ב'** נשארת מקומית בדפדפן ואינה חלק מהעדכון השבועי.
- **תאריכי הגאנט** (`gantt.json`) אינם מתעדכנים בסקריפט, ויש לערוך אותם ישירות.
- האתר מזהיר כשהעדכון השבועי ישן מ-10 ימים.
