# חתכי רחוב בדאשבורד (קיים | מוצע)

בלחיצה על פרויקט של רחוב בדאשבורד, בחלונית הצד מופיע בלוק "חתכי רחוב – קיים ומוצע": שני חתכים זה לצד זה, בחירה בין חלופות, והגדלה לחלון.
הבלוק מופיע רק לתכניות שיש להן חתכים ב-`public/data/sections/`.

## מה היועץ שולח
1. קובץ PNG לכל חתך: רוחב 1600 פיקסלים, רקע לבן, עד 300KB, בלי כותרת בתוך התמונה.
2. שם קובץ באנגלית: `תכנית_רחוב_[מקטע]_existing|proposed.png`, למשל `GI_hamor_A_proposed.png`.
3. טבלת אקסל לפי `sections-template.xlsx` (או CSV UTF-8), שורה לכל חתך. בעמודה "תווית" (אופציונלי) שם החתך המוצע בכפתור, למשל "מקטע A" או "שלב ביניים 21 מ'". אם לא ממלאים, התווית היא "חלופה א" לפי עמודת החלופה.
4. לכל רחוב: חתך קיים אחד, ולפחות חתך מוצע אחד (חלופה לכל חתך).

## הוספה או עדכון של תכנית (אצלנו)
```
# 1. התמונות אל public/data/sections/images/ והטבלה אל data-src/sections/<קוד תכנית>.csv
node scripts/build-sections.mjs        # בונה sections.json ובודק: קבצים חסרים, שמות, כפילויות, משקל
node scripts/match-sections.mjs        # בודק אילו פרויקטים בשכבות יציגו חתך
node scripts/match-sections.mjs --write-codes   # אופציונלי: קובע את ההתאמות כקודי פרויקט קבועים
node scripts/build-sections.mjs
npm run test:sync && npm run build
```

## איך פרויקט מותאם לרחוב
1. אם לרחוב מוגדרים קודי פרויקט (בעמודה "קוד פרויקט / GIS" או ב-`data-src/sections/codes.json`): רק הם קובעים. הקוד יכול להיות קוד GIS (למשל `2-9` בגילה) או מספר פרויקט (למשל `203` בארמון הנציב), וההתאמה היא תמיד בתוך אותה תכנית.
2. אחרת: שירות מסוג רחוב (שדרוג רחוב, שביל אופניים, נתיב תחבורה ציבורית, רחוב חדש, תנועה משולבת), ושם הרחוב מופיע **בשם הפרויקט** (לא בתיאור, שמזכיר רחובות סמוכים). "לצוף" מתאים ל"הצוף", ושם שבא אחרי המילה "צומת" לא נחשב. כינויים נוספים ב-`data-src/sections/aliases.json`.
3. שביל הליכה, חצייה, תחנה או "אחר" לא מותאמים לפי שם.

## ארמון הנציב
החתכים חולצו מהמצגת `הצעות.pptx` (שקופיות 46–52, 56, 62, 66, 72–75). 12 רחובות, 7 חתכים קיימים ו-28 מוצעים.
- התאמה לפי מספר פרויקט (`codes.json`), לפי מספרי הפרויקטים שבכרטיסי הרחוב הקיימים בדאשבורד (למשל גרונר 203/403, עולי הגרדום 201/301/401).
- הרוחב לא מוצג בתג, כי הוא מופיע בתוך השרטוט.
- חמישה רחובות מקומיים (אנוסי משהד, אדם, אלקחי, חביב, נקר) מוצגים עם חתך מוצע בלבד: במצגת אין להם חתך קיים. החתך של אנוסי משהד, אדם ואלקחי משותף, ומופיע בשלושה קבצים זהים.
- לא נכללו שני חתכי העקרונות של עולי הגרדום (שקופית 71, "עקרוני קודם" ו"לאיזון"), כי הם אינם חתך קיים או מוצע.
- ברזני: החתך הקיים משקופית 56, והמוצעים (מקטעים A, B, C) משקופית 62.
